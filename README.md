# Mobolaji Ogunbiyi — personal portfolio

https://mobolaji.builtbykora.com · Static HTML/CSS/JS, published by GitHub Pages from main. The separate studio business remains at builtbykora.com.

## Edit and build

Eight core pages are generated by `scripts/build-pages.py`; edit that source, then run:

```sh
python -m pip install Pillow
python scripts/build-pages.py
python scripts/check-site.py
node --check script.js
python -m http.server 5198 --bind 127.0.0.1
```

The four technical articles under `work-writing/` are authored HTML, with shared `styles.css` and optional article CSS. All use the same navigation, font, and footer. Keep shared changes in sync when editing the article markup. Self-hosted Onest retains its SIL OFL in `assets/fonts/`.

## Interactive samples

- Kora: `demos/kora/` is the deployable static artifact. `demos/kora-source/` contains a frozen copy of public Kora source, fixture adapter, licenses, screenshots, and build instructions. Rebuild with `npm ci --ignore-scripts` then `npm run build` there. Node22.12+ or24 required. Lazy iframe loads only when requested. No backend/provider connection; CSP disallows connection requests. Work uses the real production component; other panes are explicitly adapted samples.
- KS App: local illustration in the project page with deterministic fictional records, selection/search, task state, prepared update, activity, and reset. Not represented as a live AI or the actual product interface.
