WorldBuilder

Exploring the engineering of worlds that can grow without losing their history.

Ongoing projectDomain modeling / TypeScript / PostgreSQL

A world changes.
What should stay true?

WorldBuilder investigates that question through structured generation, immutable content, and durable state.

The idea.

A generated world should have more than a collection of disconnected answers.

I’m exploring how creative direction can become structured world data with clear identities, traceable revisions, and a workflow that can continue over time.

The current implementation.

Seed-to-Frame domain

A pure domain layer defines the initial structured world model and its rules.

Durable content

Immutable bodies and PostgreSQL-backed state separate large content from the records that coordinate work.

Provider composition

Codex SDK composition and an authentication verifier prepare the integration boundary. Current runtime exercises are scripted.

What is still being built.

The current version does not yet provide a complete generation workflow, live model dispatch, or downstream world products. I’m keeping the project here as a record of engineering exploration, with the implementation distinguished from the intended experience.
